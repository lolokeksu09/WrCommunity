# WrCommunity

Проект закрыт 27 октября 2026 года.

Рабочие файлы приложения, инфраструктурные конфигурации и средства автоматического развёртывания удалены из активной ветки. В репозитории оставлены только это уведомление и проверки закрытого состояния.

Предыдущий код доступен в истории Git. Серверное развёртывание и пользовательские данные на VDS удаляются отдельно владельцем сервера.

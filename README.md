# Android 3D Editor

Локальный 3D-редактор для Android (Kotlin, Jetpack Compose, SceneView/Filament), использующий репозиторий WrCommunity после закрытия прежнего приложения. Нет VDS, сервера, аккаунтов и телеметрии.

## Возможности v0.24.0
- Импорт, просмотр и экспорт GLB без изменения исходного файла.
- Трансформации объекта, материальные слои, независимые трансформации частей.
- Точная кисть, скульптинг, зеркальные изменения X/Y/Z и локальное сглаживание индексированной сетки.
- Редактирование отдельных вершин, выбор касанием, групповые топологические кольца и осевой drag.
- Undo/Redo, автосохранение, ручные контрольные точки, ZIP-архив проекта и библиотека нескольких моделей.
- Инспектор GLB, проверка целостности экспорта и защита от повреждённых файлов.

## Сборка
JDK 21, Android SDK 36, Gradle 9.6.0:

```bash
gradle --no-daemon :app:testDebugUnitTest :app:assembleDebug
```

Пакет `com.wrcommunity.editor.stable`, `versionName=0.24.0`, `versionCode=30`.
Для обновления установленного APK нужен **прежний постоянный JKS и тот же сертификат**. GitHub Actions публикует подписанный релиз только на доверенной ветке main при наличии signing secrets и успешной проверке сертификата. Debug APK не является обновлением установленной release-версии.

## Ограничения и проверка
Поддержка сложных GLB (скиннинг, морфы, сложные трансформации) ограничена. Группы вершин ограничены 64 правками, история скульптинга — 20 операциями. Проверки CI не заменяют запуск и визуальную приёмку на физическом Android-устройстве.

# WrCommunity

Русскоязычное mobile-first сообщество игроков Wild Rift: профили, публикации, поиск напарников, клубы и мероприятия. Самостоятельный проект; старый `wild-rift-community` не используется.

В репозитории реализовано приложение с PostgreSQL и серверной проверкой прав. Это кандидат 1.0 для локальной и тестовой эксплуатации. Статус приёмки и ограничения: [STATUS](docs/implementation/STATUS.md). Подтверждённого production-развёртывания нет.

## Локальный запуск целиком в Docker

Нужны Docker Engine с Compose v2 и Node.js 24 для генерации локальных секретов.

```bash
git clone --branch main https://github.com/lolokeksu09/WrCommunity.git
cd WrCommunity
node scripts/setup-local.mjs
docker compose -f compose.local.yml up -d --build
```

Сайт: **http://localhost:8080**. Письма подтверждения и восстановления: **http://localhost:8025** (Mailpit). Зарегистрируйтесь на сайте, откройте письмо в Mailpit и подтвердите адрес. Mailpit используется только в локальном окружении; внешняя отправка почты требует собственного SMTP.

Команда создаёт PostgreSQL, выполняет версионированные миграции, запускает API, worker и Caddy. Секреты создаются случайно в игнорируемом `.env`; существующий файл не перезаписывается. Данные и приватные медиа сохраняются в volumes. Обычная остановка сохраняет их:

```bash
docker compose -f compose.local.yml down
```

Не используйте `down --volumes` для базы с нужными данными: эта команда удаляет volumes.

## Разработка без контейнера приложения

```bash
node scripts/setup-local.mjs
npm ci
docker compose -f compose.dev.yml --profile mail up -d
npm run migrate
npm run build
npm start
```

В другом терминале: `npm run start:worker`. Сайт работает на http://localhost:3000, Mailpit — http://localhost:8025. Для редактирования интерфейса: `npm run dev` и отдельно `npm run dev:web`; канонический `APP_ORIGIN` должен совпадать с адресом браузера.

## Реализованные подсистемы

| Модуль | Поведение |
|---|---|
| Аккаунты | Email/пароль, Argon2id, подтверждение, одноразовый сброс, отзыв сессий, настройки и обезличивание при удалении |
| Приватность | `hidden` по умолчанию, явное открытие, отдельная публичность игровых полей, opt-in онлайн на сайте |
| Социальное ядро | Ленты, черновики/редакции, изображения, комментарии/ответы, лайки, закладки, подписки, полные блокировки, темы и упоминания |
| Discovery/LFG | Сервер/роль и дополнительные фильтры, объяснимые рекомендации, срок автора, адресные отклики, принятие/отказ, добровольные шифрованные контакты |
| Клубы | Каталог, независимые режимы доступа, роли, заявки/согласия/псевдонимы, передача владения, лимит 3, подтверждённое закрытие |
| Клубный контент | Премодерация, отдельные редакции, закрепление, закрытый архив, постмодерация комментариев и клубные жалобы |
| Мероприятия | Общая клубная лента, разрешения ролей, лимит мест под блокировкой строки, регистрация/отмена/изменения |
| Уведомления | Внутренний центр и категории, PostgreSQL outbox, повторная проверка ACL |
| Модерация | Отдельные роли платформы, жалобы/решения/санкции, аудит и ограничения клубов |
| Медиа | Проверка сигнатуры/размера/пикселей, перекодирование без EXIF, приватное хранение и ACL на каждом чтении |

Опросы, репосты, личные чаты, нативные приложения и верификация Riot не входят в согласованную первую поставку. Игровые данные указываются игроком вручную. Установочный сценарий не создаёт демонстрационных пользователей или активности.

## Проверки

Используйте отдельную тестовую PostgreSQL 18 и `NODE_ENV=test`; тестовые фикстуры не предназначены для production.

```bash
npm run typecheck
npm run build
npm run migrate
npm test
npm run test:e2e
npm run check:secrets
npm run backup:verify
npm run smoke:docker
```

CI запускает PostgreSQL integration tests, браузерные сценарии, проверку восстановления и независимый Docker smoke. Результаты фактического запуска, скриншоты и известные ограничения перечислены в [отчёте](docs/implementation/STATUS.md), а не выводятся из наличия тестовых файлов.

## Production

[Эксплуатация, конфигурация, миграции и резервные копии](docs/implementation/OPERATIONS.md). `compose.yml` публикует только Caddy 80/443; PostgreSQL/API закрыты внутренней сетью. Нужны настоящий домен, внешняя SMTP-доставка и собственные секреты. Production не изменяется автоматически.

Перед внешними пользователями остаются отдельные условия запуска: правовые документы/возраст/retention, права на UGC и материалы, эксплуатационная модерация и проверенная политика резервного хранения. Кодовая лицензия пока не выбрана.

## Архитектура и документация

React 19, TypeScript strict, Vite, React Router Data mode; Node.js 24, Fastify 5; PostgreSQL 18, параметризованный типизированный SQL-слой и SQL-миграции; общий монолит и отдельный worker. Без Redis, Kafka и Elasticsearch.

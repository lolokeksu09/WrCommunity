# WrCommunity

Русскоязычное mobile-first сообщество игроков Wild Rift: профили, публикации, поиск напарников, клубы и мероприятия. Самостоятельный проект; старый `wild-rift-community` не используется.

Работающий технический пилот 1.0 использует реальные API и PostgreSQL. [STATUS](docs/implementation/STATUS.md) содержит единую запись подтверждённой поставки, покрытие и условия публичного запуска. Для текущего состояния сверяйте фактические main, RELEASE и VDS.

[AGENTS](AGENTS.md) задаёт порядок работы, [CONTINUATION](docs/implementation/CONTINUATION.md) — снимок задачи и ссылку на её окончательный результат в PR. [Навигация по документации](docs/README.md) разделяет инструкции, спецификации и архив.

## Локальный запуск целиком в Docker

Нужны Docker Engine с Compose v2 и Node.js 24 для генерации локальных секретов.

```bash
git clone --branch main https://github.com/lolokeksu09/WrCommunity.git
cd WrCommunity
node scripts/setup-local.mjs
docker compose -f compose.local.yml up -d --build
```

Сайт: **http://localhost:8080**. Письма подтверждения и восстановления: **http://localhost:8025** (Mailpit). Зарегистрируйтесь на сайте, откройте письмо в Mailpit и подтвердите адрес. Mailpit используется только в локальном окружении; внешняя отправка почты требует собственного SMTP.

Команда создаёт PostgreSQL, выполняет версионированные миграции, запускает API, worker и Caddy. Секреты создаются случайно в игнорируемом `.env`; существующий файл не перезаписывается. Данные и приватные медиа сохраняются в volumes. Обычная остановка сохраняет их:

```bash
docker compose -f compose.local.yml down
```

Не используйте `down --volumes` для базы с нужными данными: эта команда удаляет volumes.

## Реализованные подсистемы

| Модуль | Поведение |
|---|---|
| Аккаунты | Email/пароль, Argon2id, подтверждение, одноразовый сброс, отзыв сессий, настройки и обезличивание при удалении |
| Приватность | `hidden` по умолчанию, явное открытие, отдельная публичность игровых полей, opt-in онлайн на сайте |
| Социальное ядро | Ленты, черновики/редакции, изображения, комментарии/ответы, лайки, закладки, подписки, полные блокировки, темы и упоминания |
| Discovery/LFG | Общий выбор ролей с совместимостью старых подписей, курсорная догрузка игроков/рекомендаций/LFG, сервер/роль и дополнительные фильтры, объяснимые рекомендации, срок автора, адресные отклики, принятие/отказ, добровольные шифрованные контакты |
| Клубы | Каталог с существующими обложками и вкладкой своих клубов, независимые режимы доступа, роли, заявки/согласия/псевдонимы, передача владения, лимит 3, подтверждённое закрытие |
| Клубный контент | Премодерация, отдельные редакции, закрепление, закрытый архив, постмодерация комментариев и клубные жалобы |
| Мероприятия | Общая клубная лента, разрешения ролей, лимит мест под блокировкой строки, регистрация/отмена/изменения |
| Уведомления | Внутренний центр и категории, PostgreSQL outbox, повторная проверка ACL |
| Модерация | Отдельные роли платформы, жалобы/решения/санкции, аудит и ограничения клубов |
| Медиа | Проверка сигнатуры/размера/пикселей, перекодирование без EXIF, приватное хранение и ACL на каждом чтении |

Возврат назад восстанавливает догруженные страницы и прокрутку с повторной загрузкой актуальных данных. Незавершённые комментарии и ответы сохраняют ввод между маршрутами в текущем приложении; выход/смена аккаунта очищает этот буфер. В списках реакции обновляют только затронутый пост. Мобильные фильтры сворачиваются после выбора условий, выбранные значения и сброс остаются видны.

Первые шаги в своём профиле показывают подтверждение почты и заполненность игровых предпочтений; блок можно свернуть. В поиске можно явно применить свой сервер и одну роль, сохранив остальные фильтры. Отклики LFG объясняют следующий шаг, а обмен контактами показывает два отдельных согласия, обновление и отзыв.

Длинные публикации можно развернуть и свернуть прямо в списке; отдельная ссылка открывает страницу поста. Кнопка появляется при фактическом обрезании текста.

Собственный профиль показывает краткую игровую карточку и группы команд. Текст редактора восстанавливается после обновления в той же вкладке; буфер очищается при выходе/смене аккаунта и публикации. Для долговременного хранения остаётся кнопка «Сохранить черновик» на сервере.

Опросы, репосты, личные чаты, нативные приложения и верификация Riot не входят в согласованную первую поставку. Игровые данные указываются игроком вручную. Установочный сценарий не создаёт демонстрационных пользователей или активности.

## Production

[Управление VDS через GitHub Actions](docs/implementation/VDS-DEPLOYMENT.md): ограниченный SSH-доступ, проверенный SHA, резервная копия перед обновлением и браузерная проверка. Автоматический деплой после FULL в main включён; подтверждение конкретной поставки — [STATUS](docs/implementation/STATUS.md). Текущую active_revision сверяйте с фактическим RELEASE.

[Эксплуатация, конфигурация, миграции и резервные копии](docs/implementation/OPERATIONS.md). `compose.yml` публикует только Caddy 80/443; PostgreSQL/API закрыты внутренней сетью. Нужны настоящий домен, внешняя SMTP-доставка и собственные секреты. Обновление пилотного VDS выполняется автоматически после успешных обязательных заданий CI для push в `main`, пока активен `WRC_DEPLOY_ENABLED`.

Перед внешними пользователями остаются отдельные условия запуска: правовые документы/возраст/retention, права на UGC и материалы, эксплуатационная модерация и проверенная политика резервного хранения. Кодовая лицензия пока не выбрана.

## Архитектура и документация

React 19, TypeScript strict, Vite, React Router Data mode; Node.js 24, Fastify 5; PostgreSQL 18, параметризованный типизированный SQL-слой и SQL-миграции; общий монолит и отдельный worker. Без Redis, Kafka и Elasticsearch.

Клубная личность использует общий выбор игровых ролей с сохранением старых нестандартных значений. Встреча показывает время с часовым поясом и следующий шаг для участия: вход, подтверждение почты, вступление/ожидание заявки или запись.

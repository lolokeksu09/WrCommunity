# WrCommunity

Проект закрыт 27 октября 2026 года.

Исходный код, конфигурация, CI/CD и документация приложения удалены из активной ветки `main` по решению владельца. История Git сохранена для возможного восстановления.

Это изменение репозитория не удаляет запущенное приложение или данные на VDS: остановка серверного развёртывания выполняется отдельно.

# 3D Editor Stable v0.12 — восстановление незавершённого проекта

## Сценарий

После импорта GLB приложение однократно сохраняет его приватную копию в `filesDir/editor-session/model-<UUID>.glb`. Пользователь продолжает редактировать модель в текущем режиме. Каждые ~600 мс после последнего изменения сохраняется небольшой атомарный `draft.json`, содержащий только:

- оригинальный GLB (имя файла, размер, SHA-256), имя модели;
- текущие глобальные перемещения/повороты/масштаб;
- выбранные видимые материалы, преобразования частей;
- применённые деформации, настройки кисти, выбранную часть;
- последний ракурс камеры.

При следующем запуске размер и SHA-256 исходного GLB сверяются до восстановления. Если черновик неполный или повреждён, он **не загружается**; приложение сообщает об ошибке и позволяет открыть файл вручную. Исходные документы пользователя в Downloads и SAF не изменяются.

Обновление черновика происходит через временный файл, синхронизацию и rename в той же приватной папке. Старый GLB очищается только после коммита нового JSON. Смена модели начинает новый черновик, а внешний экспортированный GLB сохраняется отдельно через обычную проверенную процедуру.

## Ограничения

- Восстанавливается **текущее состояние**, а не полная история Undo/Redo до перезапуска. После запуска история начинается с восстановленной позиции.
- Один активный черновик за раз. Импорт новой модели заменяет активную сессию; её исходный файл остаётся в системной папке пользователя.
- После удаления приложения или очистки его данных приватный черновик пропадёт. Для долговременного хранения использовать **Сохранить GLB**.
- Автосохранение асинхронное и имеет debounce 600 мс: при принудительном аварийном завершении непосредственно после правки последние доли секунды изменений могут не попасть в черновик.
- Постоянная копия исходной модели занимает место в приватном хранилище до 150 МБ, но не пересоздаётся после каждого движения кистью.
- Поддержка одной активной сессии, не система многопроектных слотов.

## Проверки

- Android unit tests: JSON round-trip всей сессии, SHA-256 mismatch, запрет path traversal, отказ при >20 strokes, переключение модели без преждевременной потери старого черновика.
- Текущие GLB import/export, нормали, BVH и другие регрессии — через CI.
- На реальном Lenovo Legion Y70 остаётся проверить закрытие и повторное открытие приложения, правку до закрытия, недостаток места в хранилище и успешный экспорт восстановленного GLB.

Сохраняется applicationId `com.wrcommunity.editor.stable`, versionCode 17. Подпись только прежним сертификатом. Не трогает VDS или исходные пользовательские документы.

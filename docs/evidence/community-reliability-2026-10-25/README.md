## Среда и проверенные действия

- Локальный URL `http://localhost:13000`; изолированные PGlite18.6 и Chromium153. Docker/штатный PostgreSQL недоступны локально. Конкурентность PostgreSQL проверяет неизменённый FULL CI; существующая lock-race проверка исключалась только временной локальной командой, не кодом/CI.
- Playwright: desktop 1280 × 720, Pixel7 412 × 839. Два новых сценария сначала воспроизвели дефекты RED, затем 4/4 прошли за 12.9 с. Регистрация ошибки/ARIA/фокус без запроса; 63 уведомления и старое непрочитанное, счётчик и чтение без сброса глубины; 41 собственная жалоба внутри общей очереди, старое обращение и разрешённый LFG-контекст/ссылка; конфликт после загрузки изображения и перехода между маршрутами, сохранение имени без перезаписи чужой биографии; убрать/вернуть аватар и убрать оба изображения с проверкой nullable PATCH.
- API: 3 новые регрессии RED → GREEN, 11 выбранных API/ACL/CSRF прошли за 9.35 с; дополнительный финальный прогон новых 3/3. Включены >200 уведомлений, >100 жалоб, микросекунды и scope курсоров, hidden/block/revoked-consent и безопасные ошибки без секретных значений.
- Просмотрены шесть снимков ниже. Мобильные full-page снимки могут перемещать фиксированную шапку/нижнюю навигацию при сшивке Chromium; сами по себе они не измеряют перекрытие в viewport. Проверены действия, клавиатурный фокус, тексты и отсутствие горизонтального overflow; независимым аудитом WCAG это не является.
- После восстановления чата временные runtime/logs утрачены; сохранённый `test-results/.last-run.json` содержит `status: passed`. Это прежний результат, а не повторный прогон. Повторно выполнены типы, полная сборка, 31 L1 и поиск секретов — success. Affected-plan выполнен относительно полного базового SHA; это план, не запуск тестов. Контроль нативной среды — предстоящий FULL/RELEASE на окончательном SHA.

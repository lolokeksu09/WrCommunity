# 3D Editor Stable v0.13.0 — резервное восстановление проекта

## Поведение

- Перед заменой `draft.json` приложение сохраняет предыдущий **структурно корректный** снимок как `draft.backup.json`. Копируется только JSON (до 64 КБ); GLB размером до 150 МБ не дублируется.
- Резервное состояние создаётся только при редактировании **того же исходного GLB**. При подтверждённой смене модели старый резерв удаляется, а старый исходник очищается только после успешного коммита нового.
- При запуске сначала проверяется текущий `draft.json`. Если он повреждён или отсутствует, резервный файл также проходит строгий разбор, проверку размера GLB и SHA-256.
- При удачном восстановлении резерва пользователь видит предупреждение, что самые последние правки могли быть утрачены. Если оба черновика повреждены или GLB не проходит SHA-256, восстановление блокируется.
- Восстановление и запись защищены общим mutex от гонок; атомарная запись из v0.12.1 и сериализация запросов сохранены.

## Проверки и ограничения

- Тесты: возврат предыдущего корректного состояния при сломанном основном JSON; отказ при двух сломанных снимках; исключение восстановления старой модели после импорта другой; запрет обхода SHA-256 исходной модели.
- Не создаётся отдельный проект и не сохраняется Undo/Redo между запусками. Резервная копия — одна предыдущая успешная запись **для того же исходника**, не журнал версий.
- При удалении данных приложения оба снимка будут удалены. Для долговременного хранения необходим явный экспорт GLB.
- Визуальная приёмка и сценарии перезапуска на Lenovo Legion Y70 (Android 16) остаются отдельной проверкой.
- `applicationId = com.wrcommunity.editor.stable`, прежний сертификат, versionName **0.13.0**, versionCode **19**. Не менять VDS и пользовательские оригинальные документы.
- PR остаётся draft, без merge/release до проверки на устройстве. Подписанный APK требует уже существующий signing key GitHub Actions.

# 3D Editor v0.7.0 — выбор центра скульптинга касанием

## Сценарий

1. Открой GLB и выбери **Слои → Править → Форма**.
2. Нажми **Выбрать центр касанием**. Закроется нижняя панель.
3. Коснись выбранной области на 3D-модели. Камера временно не реагирует на жесты.
4. Приложение преобразует 3D-попадание collision shape в локальные координаты объекта, затем в проценты X/Y/Z от границ выбранного материала.
5. Проверь радиус, ось и силу и нажми **Применить деформацию**. Простое касание не изменяет сетку.

Точка является **приближённой**: SceneView collision hit не гарантирует пересечение с конкретным треугольником; группу материалов пользователь выбирает сам. Неверная или внешняя точка отклоняется, а ручной ввод сохранён.

Автовыбор доступен только для простого GLB с одним узлом меша и без промежуточных преобразований, где корректно определены `POSITION min/max`. На сложных сценах используй ручную настройку. Если выбранная часть уже трансформирована отдельно, автопозиционирование отключено.

## Проверки

- Тесты нормализации X/Y/Z, выбора отдельного материала, отказа для внешних/NaN координат и сцен с преобразованием.
- Регрессионные тесты GlbSculpt, GLB-exposure, normals, истории.
- Вспомогательные проверки по двум исходным GLB.
- Android CI: compile, unit tests, стандарт. Физический Android и точность попадания ещё проверить отдельно.

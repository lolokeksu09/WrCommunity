# План: техническое продолжение аудита WrCommunity — 26.10.2026

База: `e3ddd73cfdb31c191992b8ca3497936f6ac07ae1`
Ветка: `feature/audit-followup-2026-10-26`

## Цель

Устранить подтверждённые низкорисковые проблемы интерфейса и добавить автоматические проверки, которые защищают качество сайта после аудита.

## Объём

1. Добавить явные размеры и корректные loading-параметры для пользовательских изображений, чтобы уменьшить CLS.
2. Улучшить перенос длинного пользовательского текста и идентификаторов без ломки обычных слов.
3. Добавить CI-проверки доступности и интерфейсных анти-паттернов для существующего Playwright-пайплайна.
4. Обновить документацию текущего состояния, ограничений и следующего продуктового этапа.
5. Не менять схему базы, API-контракты, приватность, production-секреты и VDS-домен.

## Приёмка

- `npm run typecheck`, `npm run build`, `npm run test:l1` успешны.
- Существующие API/desktop/mobile jobs остаются без изменений по контрактам.
- Новые проверки запускаются в CI и не требуют production-аккаунтов.
- Основные изображения имеют зарезервированные размеры.
- На мобильном и desktop нет горизонтального overflow.

## Риски

- Изменения image sizing должны сохранить текущие crop/contain-правила.
- Accessibility-проверка не должна создавать пользователей или отправлять данные.
- Публичный домен/TLS, внешний SMTP и правовые условия требуют отдельной эксплуатационной настройки и не входят в кодовый патч.

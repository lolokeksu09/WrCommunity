# 3D Editor Stable v0.20.0 — симметричный скульптинг геометрии

## Назначение

Первый патч новой фазы: **не каталог проектов и не оболочка приложения, а моделирование геометрии**. Изменения выполняются в тех же POSITION-вершинах, что и обычная кисть, затем проходят существующий пересчёт NORMAL (когда в исходном GLB есть поддерживаемые NORMAL), попадают в предпросмотр и экспортируемый GLB.

## Управление

В панели **Слои → выбор материала → Форма (скульптинг)** есть настройка:

- **Выкл** — прежняя одиночная кисть.
- **X** — зеркальная обработка вдоль локальной оси X материала.
- **Y** — аналогично для Y.
- **Z** — аналогично для Z.

Плоскость отражения — **середина исходного AABB выбранной группы материалов** по выбранной оси, а не мировой ноль, не глобальная ось сцены и не ось камеры. Центры представлены нормализованными координатами 0–100. Например, при X=20 симметричная кисть создаёт парную точку X=80.

Если исходная деформация направлена вдоль отражаемой оси (например, +X при симметрии X), зеркальная деформация направлена обратно (−X); для касательной оси направление остаётся прежним. Это нужно для физически отражённой формы.

При нанесении кисти через ручные координаты или по касанию/пути **весь набор оригинальных и зеркальных операций добавляется одним действием Undo/Redo**. Исходный GLB не изменяется; экспорт/preview применяют последовательность к копии геометрии.

Кисть точно на плоскости отражения с касательным направлением применяется один раз, а не с удвоенной силой. Нормальная деформация прямо на плоскости имеет встречную зеркальную операцию и не сдвигает шов (операции компенсируются).

Ограничение истории остаётся **20 деформаций**: зеркальные операции тоже учитываются. Если точек пути слишком много, команда явно сообщает о нехватке лимита и ничего не добавляет. Выберите более короткий путь или сохраните текущий GLB.

Выбранная ось симметрии хранится в JSON черновика и ZIP проекта, восстанавливается с контрольной точкой и при переключении проектов. Старые черновики без поля `symmetryAxis` автоматически считаются `0` (выключено); формат данных остаётся `1`.

## Проверки

Unit tests: X (центр и знак перемещения), Y/Z, отсутствие двойной деформации на шве, один Undo для зеркального пути, лимит истории, отказ от неправильной оси, совместимость старых черновиков, **фактическая симметрия координат POSITION внутри экспортируемого GLB**. Прежние тесты GlbSculpt и GlbNormals остаются без изменений.

Версия `0.20.0`, code `26`, package `com.wrcommunity.editor.stable`. Подписывать прежним сертификатом. Ручная приёмка на Lenovo Legion Y70 отдельно.

## Технические границы

- Это зеркальное применение скульпт-операций, **не топологическое Mirror Modifier** и не создание новых половин сетки.
- Точность результата зависит от геометрической симметрии выбранной группы и наличия корректного glTF POSITION.
- Скелет, morph targets и анимации продолжают иметь прежние ограничения; инструмент не обещает их поддержку.
- При сочетании зеркального режима и кисти вблизи шва перекрывающиеся области могут влиять на общие вершины. Для стандартных симметричных сеток это ожидаемое сложение одинаковых/зеркальных влияний.
- Нет вмешательства в `WrCommunity/main`, проекты пользователя не удаляются, VDS не затрагивается.

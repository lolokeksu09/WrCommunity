**Реализация 1.0:** приложение, Docker-запуск, API и проверки теперь находятся в репозитории. Актуальные результаты M0–M12 и оставшиеся условия запуска: [отчёт реализации](implementation/STATUS.md). Ниже сохранён исходный продуктовый план; его исторические чекбоксы не заменяют этот отчёт.

**Статус:** план работ, не обещание сроков выпуска.  
**Основной принцип:** сначала согласованное поведение и безопасность, потом производство.  
**Платформа первого релиза:** мобильный веб-сайт для русскоязычных игроков Wild Rift.

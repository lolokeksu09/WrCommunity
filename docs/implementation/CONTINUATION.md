## Ограничения

Публичный запуск всё ещё требует отдельного решения по домену/TLS, внешнему SMTP, юридическим текстам, retention, UGC-модерации и мониторингу. Внешний браузер в текущей сессии не использовался для обхода TLS-предупреждений.

## Как читать итог и продолжать

Сначала проверить состояние связанного PR. Если он объединён и его описание подтверждает RELEASE/HTTPS/VDS, задача завершена: перейти к новой задаче владельца. Если открыт, сверить последний head с планом и CI, продолжить первый незавершённый этап. После каждого этапа обновлять этот снимок и сохранять GitHub-коммит. Файл указывает последний уже существующий коммит; SHA собственного будущего коммита и финальный merge фиксируются через PR.

- [PR #21](https://github.com/lolokeksu09/WrCommunity/pull/21): API и браузерная проверка разведены по параллельным GitHub Actions runners, с отдельными PostgreSQL/Mailpit. В исторических замерах критический путь FULL уменьшился с 215–228 до 171–183 с.

Два FULL-прогона Ready PR: [153 с](https://github.com/lolokeksu09/WrCommunity/actions/runs/40108469782) и [142 с](https://github.com/lolokeksu09/WrCommunity/actions/runs/40108711972) на критическом пути. - Измерения не гарантируют ту же скорость на каждом запуске. Разделение требует больше суммарных runner-минут. `quality-gate`, `docker-smoke`, проверки SHA, TLS и VDS не ослаблены.
- **Ограничение GitHub:** по API ветка `main` на момент аудита **не защищена** (`protected: false`). Правила `AGENTS.md` требуют вручную проверять FULL/RELEASE перед merge; наличие зелёного `quality-gate` не заменяет настройки Branch protection / Rulesets администратором.

## Патч: роли и полнота поиска

Реализованы общий словарь ролей, выбор ролей в игровом профиле/LFG и русские подписи; существующие строки не мигрируются. Поиск распознаёт старые подписи и канонические значения, не используя приватные поля. Каталоги игроков, рекомендаций и LFG имеют курсорную догрузку с проверкой ACL на каждой странице, сохранением точности времён PostgreSQL и повторами сетевых запросов.

Добавлены API-регрессии для совместимости/приватности ролей, пагинации с одинаковыми датами и микросекундами, текущих блокировок/видимости и expiry; браузерная регрессия проверяет 23 результата, ошибку/повтор догрузки, смену фильтра и выбор ролей. До завершения FULL и RELEASE это описание кода, а не подтверждение нового опубликованного релиза.

Локальная проверка патча: TypeScript и сборка успешны; 31 L1-проверка успешна; 9 выбранных API-тестов успешны, затем отдельно повторены 3 новые регрессии после расширения ACL-проверок; новый E2E прошёл в desktop и mobile (2/2). Локальная БД — PGlite PostgreSQL 18.6, поэтому эти результаты не заменяют FULL на отдельном PostgreSQL в GitHub Actions. Проверка затронутых файлов потребовала expanded/security-sensitive покрытия; оно подтверждается обязательным FULL перед merge.

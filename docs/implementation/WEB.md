# Веб-интерфейс WrCommunity 1.0

Технический аудит 26.10.2026 добавил явные размеры пользовательских изображений для снижения CLS, более щадящий перенос обычного текста и обязательную статическую UI-проверку в CI. Следующий этап продукта: опросы, репосты и безопасные личные сообщения после отдельного утверждения спецификации.

Текущее поведение React SPA и ограничения для разработчика. Интерфейс использует реальные `/api/v1`, cookie-сессии и CSRF; сервер проверяет доступ к данным при чтении и изменениях. Подтверждённая поставка и результаты — [STATUS](STATUS.md), текущая задача — [CONTINUATION](CONTINUATION.md), локальный просмотр — [LOCAL-DEVELOPMENT](LOCAL-DEVELOPMENT.md).

## Сохранение незавершённого ввода

- Редактор публикации сохраняет текст, темы, ссылки на загруженные изображения и ID серверного черновика в account/route-scoped sessionStorage. Восстановление работает после reload в той же вкладке; выход, смена аккаунта и публикация очищают буфер. При недоступном хранилище остаётся память компонента и явное серверное сохранение. Байты ещё не загруженного файла не восстанавливаются; закрытие вкладки/очистка браузера не гарантируют сохранность.
- Для долговременного хранения публикации есть явная кнопка «Сохранить черновик» на сервере. Она не требуется для самого восстановления доступного sessionStorage-буфера.
- Редакторы профиля, LFG и мероприятия, комментарии и выбранная цель ответа сохраняют незавершённый ввод при переходах в текущем приложении; это не обещание восстановления всех форм после reload. Выход/смена аккаунта очищают привязанный к аккаунту ввод.
- Пароли и игровые контакты не сохраняются в browser storage. Собственный незавершённый контакт LFG остаётся в памяти текущего аккаунта/заявки при ошибке валидации и обновлении статуса; чужой контакт скрывается перед проверкой и при её ошибке. После успешного отзыва собственный контакт очищается.

## Актуальные пользовательские сценарии

Возврат к лентам и каталогам восстанавливает загруженную глубину/прокрутку с повторной проверкой данных и ACL. После реакции обновляется затронутый пост; меню закрывается с возвратом фокуса. Длинный и многострочный текст можно развернуть в карточке, свернуть или открыть отдельную страницу. Пустые подписки/поиск предлагают контекстные действия, мобильные фильтры сворачиваются после применения.

Первые шаги собственного профиля показывают подтверждение почты и заполненность сервера/роли по данным сервера. Свой сервер и одну выбранную роль можно явно применить к поиску игроков/LFG, сохранив остальные фильтры. Карточка объясняет ручной характер игровых данных. Отклики показывают статусы и следующее действие; доступность контактов определяется двумя отдельными согласиями принятой пары.

Клубный каталог показывает реальные обложки и вкладку своих клубов. Лента догружается курсором, старое доступное закрепление остаётся первым. Встречи разделены на предстоящие/прошедшие/отменённые и упорядочены по времени начала. Собственные редакции показывают проверку, причину отказа и переход к прежней публичной версии; команды управления и очереди доступны по роли.

При конфликте версии профиля редактор сохраняет исходный снимок вместе с вводом в памяти аккаунта, включая переходы между маршрутами и обновление loader после загрузки изображения. Он показывает сравнение с сервером и требует явного повторного сохранения только изменённых полей; новое изменение сервера вызывает новое сравнение. Регистрация связывает безопасные сообщения API с полями (aria-invalid/aria-describedby), переводит фокус и прокручивает к ошибке.

## Состояния, ограничения и проверка

- Для loading/empty/error предусмотрены состояния и повтор запросов. Проверки доступа выполняются сервером; публичные и игровые поля показываются только по разрешению владельца.
- Собственный список клубных публикаций сохраняет лимит 100. Старый `/clubs/:id/events` сохраняет прежний контракт; новые виды встреч используют курсорный `/feed?view=...`. Контракты: [API-clubs](API-clubs.md).
- Пароли/токены не кэшируются. Демонстрационные пользователи и активность не добавляются установкой. Опросы, репосты, полноценные личные чаты, Riot-верификация и нативные клиенты остаются вне согласованной первой поставки.
- У SPA есть skip-link, доступные имена, клавиатурные действия и reduced motion; адаптивность проверяется по матрице [TESTING-STRATEGY](TESTING-STRATEGY.md). Наличие этих механизмов не является независимым аудитом доступности.
- Сборка PR #32 предупреждала о JS около 503.20 kB (149.40 kB gzip) при пороге Vite 500 kB. Это история размера артефакта, не измерение скорости production; дальнейшая оптимизация требует замера.
- Штатный контейнер согласованно собирает web/server; неизвестный `/assets/*` возвращает 404. Исходный прототип сохранён в `prototypes/home/v6/index.html`.

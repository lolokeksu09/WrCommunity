# 3D Editor Stable v0.12.1 — сохранение при сворачивании

## Что исправлено

- После изменения модели автосохранение по-прежнему выполняется после 600 мс без новых действий.
- Дополнительно при `Activity.ON_PAUSE` текущий снимок проекта отправляется в отдельный IO worker **без debounce**. Его выполнение не зависит от жизненного цикла Compose-экрана.
- Конкурирующие записи обычного автосохранения и сохранения при сворачивании выполняются последовательно через один `Mutex`; устаревшая задача не перезапишет более позднюю успешную запись.
- При замене GLB удаляется только **предыдущий подтверждённый** приватный исходник, а не все найденные копии. Незавершённый импорт не будет удалён фоновым сохранением старого черновика.
- Восстановление читает черновик под тем же mutex, что и запись, чтобы не столкнуться с параллельным коммитом.
- Ошибка фоновой записи сохраняется в памяти процесса и показывается в редакторе при следующем `ON_RESUME`.
- Исходные GLB не перезаписываются; сохраняется прежняя схема `draft.json` с той же версией формата.

## Проверки и ограничения

- Unit: фоновое сохранение последней правки и выбранного ракурса до истечения debounce; ошибка фоновой записи не уничтожает предыдущий корректный черновик; сохранение старого черновика не удаляет ещё не закоммиченный новый импорт; запоздавшее фоновое сохранение не перезаписывает более новый снимок.
- Регрессия: все существующие Android unit-тесты и сборка APK в CI.
- **Сохранение при ON_PAUSE — best effort**: Android может завершить процесс до завершения записи, а мгновенное аварийное завершение без вызова `ON_PAUSE` не перехватывается.
- Физическое устройство Lenovo Legion Y70 (Android 16) не подключено к этой среде: установить APK поверх v0.12.0, изменить модель и сразу свернуть, принудительно завершить и открыть приложение; проверить возврат последнего изменения, затем экспорт GLB.
- Не сливать PR без подтверждения работы на устройстве. `com.wrcommunity.editor.stable` и signing key остаются без изменений. Версия **0.12.1 (versionCode 18)**.

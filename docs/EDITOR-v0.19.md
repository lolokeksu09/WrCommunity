# 3D Editor Stable v0.19.0 — переименование и независимые копии проектов

## Что нового

В разделе **«Мои проекты»** для каждого проекта доступно меню **⋮**:

- **Переименовать** — сменить отображаемое название активного или неактивного проекта. Файл GLB и его исходные буферы не меняются. Название сохраняется в каталоге, активном черновике и соответствующих контрольных точках.
- **Создать копию** — сохранить независимую копию GLB, правок и ручной контрольной точки под новым именем. Копия появляется в библиотеке как неактивный проект: его можно открыть и редактировать без изменения оригинала.
- **Удалить** — доступно только неактивному проекту, требует отдельного подтверждения; оригинал в Downloads не изменяется.

Копирование подходит для экспериментов с моделью до изменения исходного проекта, например отдельно тестировать скульптинг, формы и расположение материалов. Отмена/откат в копии не меняет состояние оригинала.

## Корректность и ограничения

- Максимум **8 проектов**, включая копии. При заполнении библиотеки копирование запрещается до освобождения места.
- Для копии дублируется весь исходный GLB — модель в 150 МиБ потребует до ~150 МиБ дополнительного места (плюс небольшие метаданные). Пользователь видит размер до подтверждения.
- При копировании проверяются SHA-256, длина исходной модели и фактически записанные байты. Любой сбой удаляет временные файлы, оставляя активный проект нетронутым.
- Проверка имени: 1–160 символов без управляющих знаков, имя никогда не используется как путь на диске.
- Запоздалое автосохранение с прежним именем не может отменить успешное переименование.
- Копия хранится только внутри приложения; внешний перенос выполняется существующим экспортом ZIP.
- Библиотека продолжает использовать прежнее приватное хранилище `files/editor-session/projects`; формат `EditorDraft` не мигрирует.

## Проверки

Шесть unit-сценариев: независимость копии, перенос контрольной точки, устойчивое переименование активного проекта, переименование неактивного и сохранение его checkpoint, недопустимые имена, запрет копии при лимите 8/повреждении SHA. Плюс существующие регрессии импорта, экспорта и автосохранения.

`applicationId=com.wrcommunity.editor.stable`, `versionName=0.19.0`, `versionCode=25`. Для обновления поверх v0.18.0 требуется прежний постоянный сертификат. `WrCommunity/main` и VDS не изменяются. Успешный CI не заменяет ручную приёмку на Lenovo Legion Y70.

## Критические обязательные тесты

| Риск | Проверка |
|---|---|
| Скрытые данные | Гостевой API, медиа, поиск, кэш, уведомления и списки не раскрывают `hidden` |
| Блокировки | Два одновременных запроса не обходят запрет прямого взаимодействия |
| Лимит клубов | Параллельное создание и передача не дают четвёртое владение |
| Отзыв согласия | Конкурирующее одобрение заявки и отзыв не создают доступ |
| Последнее место | Нельзя превысить вместимость мероприятия |
| Редактирование | Новая редакция клуба невидима до одобрения |
| Истечение LFG | После срока новые заявки запрещены независимо от задержек фонового процесса |
| Публичность архива | Открытие клубной ленты не раскрывает старые закрытые записи |
| Отмена членства | Старый URL не позволяет читать закрытую ленту |
| Удаление аккаунта | Историческое имя клубных комментариев обезличивается |

## Условия публичного запуска

Нужны результаты CI и приёмочных тестов, проверенное восстановление резервной копии, проверка прав на изображения, политика персональных данных, реальная модерация и антиспам. Пока эти условия не выполнены, статус продукта — **не готов к публичному запуску**.

Подробные концептуальные пути файлов и будущие интерфейсы могут уточняться в рамках конкретного кодового инкремента. Изменение уже согласованных правил приватности требует отдельного ревью.

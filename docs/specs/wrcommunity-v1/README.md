## Статусы

- **[CORE]** исходный контракт Social Core v1; согласованное приложение по межмодульным правилам добавляется отдельной правкой.
- **[USER]** конкретные решения пользователя в раундах 1–8.
- **[DELEGATED]** работа на основе переданного ассистенту выбора в раунде 9.
- **[DECIDED-BY-DELEGATION]** дополнительные безопасные инженерные решения этой редакции, которые можно пересмотреть при ревью.
- **[OPEN / LAUNCH GATE]** законность обработки персональных данных, правила удаления/возраст, лицензирование контента, политика жалоб и успешность фактического тестирования — не объявляются автоматически закрытыми.

## Критические правила, не подлежащие упрощению

- Скрытый аккаунт не раскрывается через список, API, кэш, медиа, рекомендации и уведомления.
- Разрешённая клубная личность скрытого участника видна только в конкретном контексте и по согласию.
- Старые клубные комментарии после выхода сохраняют подпись лишь в прежней ACL; удаление аккаунта обезличивает их.
- Блокировка A/B запрещает взаимные адресные действия, даже если оба в одном клубе.
- Новые клубные публикации требуют одобрения; редактирование создаёт новую ожидающую редакцию.
- Вместимость мероприятия и лимит трёх клубов нельзя превышать через параллельные запросы.
- Срок LFG задаёт автор; передача игровых контактов — двусторонний осознанный opt-in, не чат.

## Что разрешает пакет, а что нет

**Готово к ревью:** продуктовая модель, рабочие инженерные решения и конкретный план для команды.  
**НЕ готово:** программный продукт, CI, миграции, тесты, публичный запуск. Ни одно из этих действий пакет сам не выполняет.

**GitHub:** пользователь отдельно разрешил обновление репозитория 23 октября 2026 г. Документы опубликованы в отдельной ветке для ревью; изменения не слиты в `main` автоматически.  
**Юридическая и эксплуатационная готовность:** требуется отдельное подтверждение до публичного пилота.

# Документация WrCommunity

> [!NOTE]
> Репозиторий находится на этапе проектирования. Документация описывает принятые требования и гипотезы, а не реализованную функциональность.

## Основные документы

| Документ | Что внутри | Статус |
|---|---|---|
| [Social Core v1](specs/social-core-v1.md) | Профили, публикации, подписки, приватность, блокировка и приёмочные сценарии | Проект на утверждение |
| [ROADMAP.md](ROADMAP.md) | Этапы подготовки, реализации и контрольные точки | Рабочий план |
| [Visual Directions v1](design/visual-directions-v1.md) | Editorial Dark, Rift Immersive, Social Premium | Концепты на рассмотрении |
| [BRAND.md](BRAND.md) | Визуальные принципы, оригинальные SVG-материалы | Предварительное направление |

## Порядок утверждения

1. Зафиксировать пользовательскую цель и требования.
2. Отделить утверждённые решения от предложений.
3. Проверить противоречия, приватность, безопасность и крайние сценарии.
4. Получить утверждение спецификации владельцем.
5. Составить технический план, оценить риски, выполнить ревью.
6. Начинать реализацию только после согласования плана.

## Границы

- Этот проект не переносит код из `wild-rift-community`.
- Репозиторий не содержит готового сайта или сервера.
- Никакого автоматического деплоя сейчас нет.
- Публичный контент разрешён гостям; социальные действия требуют входа.
- Архитектура, стек, лицензия и домен ещё не утверждены.

Обнаружили противоречие? Откройте [issue](https://github.com/lolokeksu09/WrCommunity/issues) со ссылкой на соответствующий раздел.

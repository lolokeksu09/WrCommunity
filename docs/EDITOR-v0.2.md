# 3D Editor v0.2 — мобильный рабочий экран

Реализовано в ветке `feat/android-3d-editor-foundation`:

- Статус-бар и панель действий не перекрывают системные отступы.
- Темный редактор: главный объект занимает почти весь экран.
- Импорт GLB через Android SAF; модель хранится во внутреннем кэше, исходный документ не переписывается.
- Трансформация **всего объекта**: углы X/Y/Z (±15°), позиция (±0.1 единицы), размер (10–400%).
- История «Отменить / Повторить» с ограничением 50 шагов и очисткой redo-ветки после нового действия.
- Отдельная кнопка сброса камеры и безопасный сброс правок.
- Локальная эталонная картинка поверх viewport (переключение «Реф.»).
- Кнопка «Сохранить» создаёт новый GLB; оригинальная геометрия, материалы и бинарные данные не переписываются.

**Не реализовано:** скульптинг отдельных вершин/лица, ретопология, выбор отдельных мешей и анимации.

## Ограничения

- Отображение нормализовано до единичного размера для удобства просмотра, а экспорт сохраняет трансформацию в исходных координатах GLB. Поэтому относительное перемещение в предпросмотре может отличаться по визуальному масштабу у моделей с разными исходными единицами.
- Импортированный файл держится в кэше Android; после очистки кэша его требуется открыть заново.
- Проверь на реальном Lenovo Legion Y70: импорт модели 24 МБ, шаги X/Y/Z, сохранение, повторное открытие экспортированного GLB, оба режима экрана.
- Для нового APK, устанавливаемого поверх v0.1.2, нужен прежний постоянный ключ подписи. Debug APK из Actions подписан другим ключом; неподписанный release нельзя распространять как обновление.

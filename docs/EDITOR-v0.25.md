# Android 3D Editor Stable v0.25.0 — выбор участка модели касанием

## Использование
1. Открой GLB. Короткое касание видимой части модели выбирает **ближайший видимый материал** и сразу открывает его «Слои → Положение».
2. Меняй X/Y/Z, поворот Y и масштаб выбранной группы; «↶ Правка», «↷ Правка» и «Сброс» работают как прежде.
3. Закрой панель, коснись другого участка или используй список «Слои» для ручного выбора по имени.

Это выбор группы по **материалу**, а не отдельного полигона. Если разные детали используют один материал, изменяются все его поверхности.

## Реализация и ограничения
- Касание обрабатывается CPU BVH по исходным индексу/геометрии; скрытые материалы и перекрытые поверхности не выбираются.
- Для ранее перемещённых/повёрнутых/масштабированных частей луч преобразуется обратно в локальные координаты с учётом TRS. Параметр пересечения сравнивается на общем луче.
- После скульптинга/редактирования вершин picker перестраивается; асинхронное попадание отменяется после смены модели, геометрии, предпросмотра, истории частей или видимости.
- Один короткий тап выбирает. Движение дальше системного touchSlop, мультитач или отменённый жест не выбирают, камера остаётся управляемой.
- Для сложных glTF сцен, которые исходный GlbSurfacePicker не умеет разбирать (несколько узлов, skin, transform-узлы, morph targets), остаётся ручное меню «Слои».
- Исходный GLB не переписывается, изменения частей хранятся через PartHistory и экспортируются через GlbPartTransforms.

## Проверки
Unit: ближайший/скрытый материал, перевод/вращение/масштаб частей, невалидные лучи, тап против свайпа/мультитача.
Android CI: :app:testDebugUnitTest и :app:assembleDebug.
Реальную корректность расположения выделений на устройстве Lenovo Legion Y70 следует проверить после установки.

`applicationId=com.wrcommunity.editor.stable`, `versionName=0.25.0`, `versionCode=31`. Использовать предыдущий стабильный сертификат.

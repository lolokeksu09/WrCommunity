# 3D Editor Stable v0.16.0 — переносимая резервная копия проекта

## Функция

Новая строка «Архив проекта» в редакторе предлагает:

- **Экспорт ZIP**: сохраняет текущий GLB и *все* правки (общие трансформации, видимость материалов, трансформации отдельных частей, скульптинг, кисть, выбор материала и пресет камеры) в переносимый архив через Android Storage Access Framework. ZIP проверяется повторным чтением и SHA-256 по данным сохранённого документа. Пользовательский исходный GLB не изменяется.
- **Импорт ZIP**: выбирает архив через системные «Файлы», проверяет структуру архива, хеш GLB и ссылки слоёв, затем атомарно заменяет единственный текущий проект. При наличии открытого проекта требует подтверждения; при ошибке старый проект сохраняется.

Формат ZIP (две записи и ничего больше): `draft.json` — совместимый с EditorDraft JSON формата 1, `model.glb` — исходный GLB. Внутри архива нет приватного ключа, паролей, референс-фотографий или данных других приложений.

## Защита

- ZIP записывается во временное хранилище приложения с ограничением размера: GLB 150 МиБ, архив GLB+2 МиБ, JSON 64 КиБ.
- Центральный каталог ZIP проверяется `ZipFile`. Пустые, недостающие, повторяющиеся и неизвестные пути отклоняются; содержимое архива никогда не распаковывается по именам записей, что исключает Zip Slip.
- Применение проекта возможно **только после** проверки целостности GLB, SHA-256, структуры glTF и всех сохранённых ссылок на материалы.
- Если импорт оборван, повреждён или не прошёл проверку, текущий черновик остаётся прежним. Неудачные временные файлы удаляются.
- Архив содержит именно исходную сетку модели, а операции редактирования — отдельным JSON. Чтобы получить результат для других 3D-программ, используйте существующую кнопку **«Сохранить»** (экспорт изменённого GLB).

## Версия и проверки

`com.wrcommunity.editor.stable`, `versionName=0.16.0`, `versionCode=22`. Прежняя подпись обязательна.

Добавлены unit-тесты: перенос и восстановление правок, неверный хеш, неизвестные ZIP пути, неполные записи, отсутствующие материалы, обрезанный ZIP и сохранность текущего проекта при ошибке. CI выполняет Android unit, debug и unsigned release. Подпись выполняется только прежним ключом после успешного CI.

Ограничения: интерфейс и реальные GLB должны быть проверены на Lenovo Legion Y70. Остаётся один активный проект (замена подтверждается), ZIP не является облачным автосохранением и должен храниться пользователем самостоятельно. `WrCommunity/main` и VDS не изменяются.

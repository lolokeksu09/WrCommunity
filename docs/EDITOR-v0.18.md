# 3D Editor Stable v0.18.0 — библиотека проектов

## Что меняется

Редактор раньше держал один активный GLB-проект. При успешном импорте другого файла прошлую приватную GLB-копию удаляли, поэтому вернуть её вместе с правками можно было только из заранее сделанного ZIP.

С v0.18 сохранённые проекты доступны через **«Проекты»** (панель навигации и верхняя строка). Приложение хранит до **8** независимых GLB-проектов. Каждый хранит собственную исходную копию GLB, полный редактируемый JSON-черновик и ручную контрольную точку.

- Открытие нового GLB или восстановление ZIP теперь сохраняет предыдущий проект в библиотеке.
- Переключение на сохранённый проект загружает его реальный GLB, настройки, скульптинг, слои, выбор материала и камеру. Непосредственно перед переключением записываются последние ещё не попавшие в автосохранение правки.
- Поздний worker автосохранения предыдущего проекта не сможет заново сделать его активным.
- Кнопка **«Удалить»** доступна только неактивному проекту, требует подтверждения и удаляет его приватную GLB-копию; исходный файл пользователя в Downloads/SAF не затрагивается.
- Активный проект удалить нельзя. При достижении лимита 8 новая модель не заменит текущий проект: пользователь получит ошибку, и исходный черновик останется.
- Ранее установленная v0.17 с одной моделью автоматически попадает в библиотеку при первом открытии списка/сохранении, без копирования большого GLB.

## Надёжность

Данные хранятся в app-private `files/editor-session/`, проекты — в `projects/model-<UUID>.json`. Переключение защищено mutex и номером записи, файлы JSON записываются через временный файл + fsync + rename. При открытии старого проекта проверяются длина и SHA-256 его сохранённого GLB и ссылки на материалы. Старый исходный GLB не удаляется без явной команды удаления неактивного проекта.

Контрольные точки привязаны к конкретному проекту. При переключении в каталог сохраняется/восстанавливается соответствующая точка. Это *не* облачный бэкап: удаление данных приложения удалит библиотеку. Для передачи устройства или надёжного хранения экспортируйте ZIP из v0.16.

## Тесты и совместимость

- Регрессионные сценарии: две модели, сохранение несброшенных правок при switch, защита от запоздалого фонового сохранения, повреждённый source, per-project checkpoints, удаление активного запрещено, миграция старого черновика, превышение лимита восьми.
- Упрощены старые тесты, ожидавшие прежнее автоматическое удаление источника.
- `applicationId=com.wrcommunity.editor.stable`; `versionName=0.18.0`; `versionCode=24`. Для установки поверх v0.17 необходим прежний JKS/сертификат.
- `WrCommunity/main` и VDS не затрагиваются. Требуется отдельная ручная проверка работы на Lenovo Legion Y70.

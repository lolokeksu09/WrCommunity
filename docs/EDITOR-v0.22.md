# 3D Editor Stable v0.22.0 — выбор вершины касанием + экранный осевой манипулятор

## Новый рабочий сценарий

В **Слои → выбранный материал → Вершины** появилась кнопка **«Выбрать вершину касанием»**.

1. Нажать кнопку. Панель скрывается, становится доступным один тап по 3D-модели.
2. CPU-луч SceneView переводится в локальные координаты ModelNode.
3. Не на UI-потоке BVH ищет ближайший видимый треугольник, включая проверку перекрывающих материалов.
4. Из трёх вершин найденного треугольника выбирается ближайшая к точке пересечения. Возвращается **исходный** `mesh / primitive / vertex` ID.
5. Поверх модели появляется компактная панель с **X− / X+ / Y− / Y+ / Z− / Z+**, Undo и переходом к точным настройкам. Изменения входят в прежний `VertexHistory`, а значит сохраняются и экспортируются как GLB.

Дополнительный механизм построения BVH не нужен — расширен `TriangleBvh.trace`, чтобы возвращать индекс выигравшего треугольника без второй трассировки.

## Корректность

- Выбор происходит на **исходном нефильтрованном меше**, с учётом текущих вершинных правок и скульптинга. Это важно: сокрытие материалов меняет номера примитивов в превью, а правки должны адресовать **оригинальные** номера. `visibleMaterials` участвует в проверке перекрытия, поэтому скрытые материалы не блокируют выбор.
- Нельзя выбрать вершину за видимым материалом: поверхность перед ней блокирует попадание.
- Не используются догадки по ближайшему индексу во всём меше — только вершины реально пересечённого треугольника.
- Никакие исходные GLB или общие POSITION-accessor не перезаписываются. Сдвиги на экране вызывают существующее недеструктивное редактирование вершин v0.21, включая Undo/Redo, автосохранение, контрольные точки и экспорт.
- Асинхронная трассировка защищена от устаревшего запроса при смене модели, выбранного материала и видимости. При несовпадении новой сцены с прежней выбранный hit отбрасывается.
- Для выбора требуется один палец; мультитач отменяет режим.
- Предварительная трансформация отдельных частей `partEdits` отключает выбор касанием, чтобы не применять смещения в неверном пространстве. Ручной выбор по индексу остаётся.
- Как и существующая точная кисть, экранный выбор поддерживает статическую GLB-сцену с одним исходным mesh node, одним scene root, TRIANGLES и FLOAT VEC3 POSITION. Сложные трансформированные/скелетные/анимированные модели пока используют ручной ввод индекса.
- Экранный манипулятор сейчас **кнопочный осевой**, не свободно перетаскиваемый 3D-gizmo с визуальными стрелками. Шаг 0,01 / 0,1 / 1 выбирается в панели настроек.

## Регрессии

- Хит по ближней видимой поверхности выбирает вершину из пересечённого треугольника и возвращает исходные mesh/primitive IDs.
- Нельзя выбрать скрытый/перекрытый материал.
- Луч вне меша, невалидный луч и скрытый материал возвращают null.
- Вершинная правка в GLB не делает source IDs недоступными для следующего тапа.
- Существующие BVH, скульптинг, экспорт, автосохранение и ZIP-тесты остаются.

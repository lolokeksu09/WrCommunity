# Android 3D Editor Stable v0.15.0 — ручные контрольные точки

## Возможность

При открытой модели в нижней панели появились две команды:

- **Запомнить** — сохранить текущее состояние правок как отдельный ручной снимок.
- **Вернуть** — после подтверждения откатить текущую модель к этому снимку.

Снимок включает глобальную трансформацию (поворот, позиция, масштаб), видимость слоёв, трансформации материалов, список деформаций, текущую кисть, выбранный материал и пресет камеры. После восстановления история Undo/Redo начинается с контрольной точки. Откат нельзя отменить через Undo; перед ним приложение предлагает при необходимости экспортировать текущий GLB.

В отличие от автосохранения и предыдущей резервной копии, ручная контрольная точка **не перезаписывается фоновым сохранением**. Она лежит в `files/editor-session/draft.checkpoint.json` и не дублирует до 150 МБ исходного GLB. При успешном переходе к **другому** файлу модели точка удаляется, чтобы она не ссылалась на чужой или удалённый GLB.

При запуске порядок восстановления: основной черновик, автоматическая резервная копия, затем ручная контрольная точка. Каждый вариант независимо проверяет размер и SHA-256 приватной копии модели. При восстановлении из контрольной точки пользователь получает предупреждение о потере более поздних правок.

## Проверки

Добавлены пять unit-тестов:

1. Точка сохраняется независимо от нескольких автосохранений и может быть возвращена.
2. При повреждении primary и backup загрузка возвращает ручной снимок.
3. После открытия другой модели старая точка удалена.
4. Устаревший снимок нельзя записать поверх другого проекта.
5. Подмена содержимого исходного GLB не обходится через ручной снимок.

Android CI: `gradle --no-daemon :app:testDebugUnitTest :app:assembleDebug`, плюс `assembleRelease` без ключа для локальной подписи. Физический запуск UI и проверка реального GLB на Lenovo Legion Y70 требуют отдельного теста.

## Совместимость и границы

- `applicationId`: `com.wrcommunity.editor.stable`.
- `versionName`: `0.15.0`; `versionCode`: `21`.
- Прежний сертификат подписи обязателен для обновления установленной v0.14.0.
- Исходный GLB пользователя не изменяется. Контрольная точка не заменяет экспорт отдельного GLB для долгосрочного хранения.
- Доработка в отдельном draft PR, не затрагивает `WrCommunity/main` или VDS.

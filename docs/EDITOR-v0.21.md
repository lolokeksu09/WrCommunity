# 3D Editor Stable v0.21.0 — точечное редактирование вершин

## Новое в 3D-моделировании

В **Слои → выбранный материал → Вершины** появился инструмент точного перемещения отдельных вершин исходной GLB-сетки:

- выбор mesh/primitive по материалу, в том числе когда материал встречается в нескольких примитивах;
- ввод **точного индекса POSITION-вершины** (0…N-1) вместо случайной точки на экране;
- смещение по X/Y/Z с шагом **0,01**, **0,1** или **1,0** в локальных единицах сетки;
- собственная история **Undo/Redo** до 64 операций и сброс всех правок вершин;
- живой предпросмотр и экспортированный GLB содержат фактические изменённые POSITION, а не временную трансформацию просмотра;
- нормали выбранного примитива пересчитываются существующим безопасным механизмом, если формат NORMAL поддерживается.

**Важно:** это выбор по индексу; выбора вершины касанием по экрану, вершинного gizmo, edge/face-режимов и топологических операций здесь пока нет. Внутренняя сетка не делится, новых вершин не создаётся. Один импортированный GLB может содержать несколько экземпляров одного меша — смещение вершины влияет на экземпляры выбранного определения примитива. Для анимированных, skinned, morph-target и не-TRIANGLES моделей функция недоступна с явным предупреждением.

## Целостность сетки

- Правки ссылаются на индексы mesh/primitive **исходного GLB**, поэтому применяются до фильтрации материалов, которая может изменить порядок примитивов.
- Изменяемый примитив получает **собственный** FLOAT VEC3 POSITION accessor и bufferView; исходный совместно используемый буфер не затрагивается.
- Проверяются диапазоны индексов, count, bufferView, byteStride, смещения, конечность координат и лимит размера GLB.
- После записи пересчитываются AABB min/max нового accessor.
- Совместимый экспорт по-прежнему проверяет целостность GLB и повторно читает файл из Android SAF.
- В памяти/черновике правки хранятся как короткие векторы смещения, исходная GLB-копия не перезаписывается. ZIP проекта и контрольная точка сохраняют их автоматически.

## Тесты

1. Сдвиг конкретной вершины и неизменность другого примитива с общим POSITION accessor.
2. Undo/Redo и накопление последовательных смещений.
3. Отклонение несуществующих mesh/primitive/vertex, NaN и чрезмерных перемещений.
4. Отклонение skinned, animated и morph target моделей.
5. Доступные примитивы по материалам, сохранение в EditorDraft и совместимость со старыми JSON-черновиками.

Версия: `com.wrcommunity.editor.stable`, `0.21.0`, code `27`. Для обновления поверх v0.20 необходим прежний сертификат подписи. Изменения только в новой feature-ветке; `WrCommunity/main` и VDS не затрагиваются.

## Известные ограничения

- GLB большого размера может требовать значительного объёма оперативной памяти для предпросмотра/экспорта.
- Устройство Lenovo Legion Y70 и реальные модели требуют отдельной физической проверки; CI не доказывает удобство точечного редактирования на сенсорном экране.

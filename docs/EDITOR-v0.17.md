# 3D Editor Stable v0.17.0 — инспектор GLB

## Цель и пользовательская функция

Вместо небольшого всплывающего блока кнопка **Инфо** открывает прокручиваемую панель **Инспектор GLB**.

Она показывает по загруженной модели:
- исходный размер файла (МиБ), количество мешей, примитивов, узлов и сцен;
- материалы, текстуры и изображения;
- оценку количества треугольников для glTF TRIANGLES (режим 4), TRIANGLE_STRIP (5), TRIANGLE_FAN (6), включая индексированную и неиндексированную геометрию;
- сумму количества вершин по атрибуту POSITION каждого примитива;
- количество анимаций, скелетов и morph targets;
- предупреждения об ограничениях скульптинга/редактирования частей;
- текущую глобальную трансформацию, видимые материалы и число деформаций.

Числа **не являются** уникальными вершинами и фактически видимыми треугольниками: показываются определения мешей, повторные экземпляры одного меша на сцене не удваиваются. Примитивы линий/точек не учитываются в числе треугольников. Отсутствующие/некорректные сведения об акссессорах помечают статистику как неполную.

## Производительность и безопасность

- Анализ читает **только** заголовок GLB и JSON chunk. Крупный BIN не загружается в память для этого отчёта.
- JSON chunk ограничен 16 МиБ; превышение выводит сообщение **только в инспекторе**, не запрещает загрузку/редактирование GLB.
- Подсчёт выполняется в IO-контексте и отменяется, когда выбран новый исходный GLB.
- Никакие исходные документы, буферы или редакторские черновики инспектором не изменяются.
- Это обзор метаданных, **не полная проверка целостности** BIN или экспортируемой геометрии.

## Проверки

Новые unit-тесты: indexed/unindexed triangles/strips/fans, повторные экземпляры мешей, предупреждения animation/skin/morph, неверный accessor, повреждённый размер GLB. Прежние тесты импорта, экспорта и резервного копирования остаются.

Релизные значения: `applicationId=com.wrcommunity.editor.stable`, `versionName=0.17.0`, `versionCode=23`. Только прежний постоянный сертификат подходит для обновления поверх v0.16.0.

Отдельная проверка интерактивной панели на Lenovo Legion Y70 остаётся обязательной. Изменения не затрагивают `WrCommunity/main` или VDS.

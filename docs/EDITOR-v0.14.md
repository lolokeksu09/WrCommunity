# 3D Editor Stable v0.14.0 — безопасная замена модели

## Исправления

1. Новый импорт не становится активным сразу после копирования в приватное хранилище. Сначала выполняются чтение GLB-слоёв и подготовка модели, затем **атомарная запись нового стартового черновика**, и только после успешной записи переключается UI.
2. Если запись нового черновика не удалась, предыдущий проект и его состояние остаются восстановимыми. Незавершённая приватная копия импортированного GLB удаляется только если на неё не ссылаются текущий или резервный черновики; пользовательский SAF-документ никогда не удаляется.
3. Если текущая модель изменена (положение, поворот, размер, видимость слоёв, трансформации материалов или деформации), кнопка «Открыть» показывает подтверждение, что текущий **единственный** черновик будет заменён. Отмена сохраняет редактор без изменений. Предлагается экспортировать текущую модель кнопкой «Сохранить» до замены.
4. При открытии нового файла настройки кисти теперь сбрасываются на валидный материал новой модели, а не наследуются от предыдущей.
5. Импорт без редактируемых слоёв отклоняется понятным сообщением без замены текущего черновика.

## Проверки

- Unit: новый импорт восстановим немедленно после commit; неудачный стартовый снимок не уничтожает старый и очищает непривязанный приватный GLB; импорт с пустым набором слоёв не заменяет проект.
- Существующие тесты безопасности чтения, импорта, экспорта, редактирования, черновиков и SHA-256 выполняются в Android CI.
- UI-диалог и быстрый сценарий «открыть GLB → завершить приложение → открыть снова» требуют ручной проверки новой сборки на Lenovo Legion Y70.
- Восстановление одного активного проекта остаётся ограничением архитектуры. **Черновик не заменяет ручной экспорт GLB.**

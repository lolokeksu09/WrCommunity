# 3D Editor Stable v0.11.0 — локальное сглаживание модели

## Функция

В «Слои → Править → Форма» доступны **Сдвиг** и **Сгладить**. В режиме сглаживания выбирается центр и радиус (в том числе точной кистью по поверхности), сила от 1 до 20%, затем действие «Сгладить область». Используется однопроходное лапласово сглаживание: для каждой вершины внутри радиуса одновременно вычисляется средняя позиция соседей по индексированным треугольникам, смешивается с исходной позицией пропорционально силе и плавному затуханию на границе кисти.

## Безопасность

- Исходный GLB не перезаписывается; для изменённого материала создаётся отдельный POSITION accessor и bufferView.
- Другие материалы, включая общие исходные буферы, не меняются.
- После изменения положения вершин существующий `GlbNormals` пересчитывает нормали только затронутых участков.
- Действие интегрировано в SculptHistory и поддерживает Undo/Redo, в том числе единый откат всего пути пальца.
- Режим не меняет топологию, не создаёт и не удаляет вершины. Использует текущие связи треугольников, поэтому открытые края могут немного стягиваться — применяй малую силу.
- Требуются `TRIANGLES` с корректными индексами `UNSIGNED_BYTE` / `UNSIGNED_SHORT` / `UNSIGNED_INT`. Неиндексированные примитивы для сглаживания отклоняются. Остальные ограничения скульптинга на анимации/скины/морфы сохраняются.

## Верификация

- JUnit `GlbSmoothingTest`: уменьшение локального выступа, сохранность другого материала и оригинального BIN, смешанный путь с Undo/Redo, повреждённые индексы и проверки диапазона.
- Регрессия всего существующего набора `GlbSculptTest`, `GlbNormalsTest`, `TriangleBvhTest`, `GlbSurfacePickerTest`.
- Android CI: `:app:testDebugUnitTest :app:assembleDebug` и Project Workflow Standard.
- На реальном Lenovo Legion Y70 визуальную точность, жесты и освещение всё ещё необходимо проверить отдельно; unit-тесты её не подтверждают.

# Android 3D Editor — особенности проекта

Версия в разработке: **v0.2.0**. Основа GLB-просмотра подтверждена на Lenovo Legion Y70 пользовательским скриншотом v0.1.2. Новые операции v0.2 требуют отдельной проверки на устройстве.

## Решения владельца

| Поле | Решение |
|---|---|
| Цель | Минималистичный Android 3D-редактор для исправления персонажей, без лишних возможностей |
| Репозиторий | `lolokeksu09/WrCommunity`, разработка в PR #62 |
| Устройство | Lenovo Legion Y70 с Android 16 |
| Приоритет | Сначала работоспособность GLB и полезные инструменты редактирования, затем сложный скульптинг |
| Дизайн | Native Android / Material 3, современный AMOLED, минимум второстепенных экранов |
| Данные | Пользовательские модели и референсы остаются локальными; исходный GLB не переписывается |
| Инфраструктура | Сборка в GitHub Actions; без изменений VDS и сервера старого проекта |
| Доставка | APK с тем же постоянным сертификатом подписи, без публикации приватного ключа |

## Обязательные границы

Экспорт трансформации всего GLB не является скульптингом сетки, лица или волос. Не заявлять обратное. Сборка CI не равна визуальной проверке на телефоне. PR не сливать до разрешения владельца.

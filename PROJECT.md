# Особенности проекта

Статус: старт Android 3D Editor, первая версия — просмотр GLB.

## Подтверждённые решения владельца

| Поле | Решение |
|---|---|
| Цель | Собственный простой Android 3D-редактор для доводки импортируемых персонажей |
| Репозиторий | `lolokeksu09/WrCommunity` (повторное использование закрытого репозитория) |
| Приоритет | Нужные действия, без второстепенных функций и перегруженного интерфейса |
| Платформа | Android; первый тестовый телефон пользователя — Lenovo Legion Y70 с Android 16 |
| Начальный сценарий | Открыть существующую GLB, осмотреть её со всех сторон и выбрать следующую нужную операцию |
| Что исключено сейчас | Социальные функции WR Community, аккаунты, VDS, AR, аналитика, облачное хранение, реклама |
| Поставка | Отдельная ветка и PR, APK после подтверждённой CI-сборки; без самостоятельного деплоя на VDS |
| Данные | Пользовательские GLB остаются локально на устройстве; публикация образцов без отдельного разрешения запрещена |

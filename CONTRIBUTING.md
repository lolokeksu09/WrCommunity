# Участие в WrCommunity

Спасибо за интерес к проекту. Сейчас идёт **продуктовое проектирование**: спецификации обсуждаются, но код сайта ещё не создан.

## Что можно предложить сейчас

- Уточнения к [Social Core v1](docs/specs/social-core-v1.md): права доступа, приватность, подписки, блокировки и граничные случаи.
- Пользовательские сценарии и проблемы навигации на телефоне.
- Идеи для клубов, поиска единомышленников и контента.
- Замечания к доступности и языку интерфейса.
- Исправления неточностей документации.

Создайте [issue](https://github.com/lolokeksu09/WrCommunity/issues/new/choose), объясните задачу, результат и связанные разделы спецификации. Для новых функций полезно назвать пользовательскую проблему, а не только желаемый элемент интерфейса.

## Pull Requests

1. Сначала обсудите масштабные изменения в issue.
2. Не считайте все предложения в спецификациях утверждёнными решениями.
3. Ограничивайте PR одной логической задачей.
4. Описывайте причину и результат изменения.
5. Для технических правок указывайте проверку, когда появится рабочий стек.

Пока техническая архитектура и лицензия не утверждены, пожалуйста, **не отправляйте большие реализации без предварительного согласования**.

## Безопасность

Не публикуйте токены, пароли, личные данные и подробности уязвимостей в Issues или PR. См. [SECURITY.md](SECURITY.md).

## Авторские права и лицензирование

Отдельная лицензия пока не выбрана; не предполагайте, что публичный репозиторий открыт для свободного распространения кода и материалов. Прежде чем предлагать значительные кодовые или графические материалы, согласуйте условия их использования с сопровождающим.

Спасибо за вклад в идею и качество продукта.

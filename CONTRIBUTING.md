# Участие в WrCommunity

Спасибо за интерес к проекту. Реализован кандидат WrCommunity 1.0. Для запуска и проверок используйте [README](README.md); текущие результаты — в [STATUS](docs/implementation/STATUS.md).

## Что можно предложить

- Уточнения к [Social Core v1](docs/specs/social-core-v1.md): права доступа, приватность, подписки, блокировки и граничные случаи.
- Пользовательские сценарии и проблемы навигации на телефоне.
- Идеи для клубов, поиска единомышленников и контента.
- Замечания к доступности и языку интерфейса.
- Исправления неточностей документации.

Создайте [issue](https://github.com/lolokeksu09/WrCommunity/issues/new/choose), объясните задачу, результат и связанные разделы спецификации. Для новых функций полезно назвать пользовательскую проблему, а не только желаемый элемент интерфейса.

## Pull Requests

1. Согласуйте объём масштабных изменений в issue или с владельцем в рабочем чате; сохраните решение и план в GitHub до кода.
2. Не считайте все предложения в спецификациях утверждёнными решениями.
3. Ограничивайте PR одной логической задачей.
4. Описывайте причину и результат изменения.
5. Для изменений интерфейса запустите актуальную локальную сборку по [LOCAL-DEVELOPMENT](docs/implementation/LOCAL-DEVELOPMENT.md) на тестовых данных, проверьте затронутые экраны в мобильном/десктопном размерах и укажите SHA/diff, URL, viewport, действия, фактический результат и пути просмотренных снимков. Для правок документации достаточно проверить факты/ссылки; обязательный CI сохраняется.
6. Сохраняйте законченные этапы коммитами, документацию — в том же PR, точку продолжения — в [CONTINUATION](docs/implementation/CONTINUATION.md). Правила всех стадий и итогового отчёта: [AGENTS](AGENTS.md), выбор проверок: [TESTING-STRATEGY](docs/implementation/TESTING-STRATEGY.md).

Архитектура реализации зафиксирована в `docs/specs/wrcommunity-v1/Technical-Architecture-v1.md`. Изменения приватности, прав и существенного продуктового поведения согласуются отдельно; перед PR запускаются TypeScript, сборка и необходимые PostgreSQL/E2E-проверки. Лицензия пока не выбрана.

## Безопасность

Не публикуйте токены, пароли, личные данные и подробности уязвимостей в Issues или PR. См. [SECURITY.md](SECURITY.md).

## Авторские права и лицензирование

Отдельная лицензия пока не выбрана; не предполагайте, что публичный репозиторий открыт для свободного распространения кода и материалов. Прежде чем предлагать значительные кодовые или графические материалы, согласуйте условия их использования с сопровождающим.

Спасибо за вклад в идею и качество продукта.

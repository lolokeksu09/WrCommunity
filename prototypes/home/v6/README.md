# Главная WrCommunity — дизайн-прототип v6

**Текущая зафиксированная версия:** `v6 Editorial Social` (23 октября 2026 г.).  
**Статус:** выбранная визуальная база для дальнейшей работы, **не финальный дизайн и не релиз сайта**.

## Просмотр

[Открыть исходный HTML-файл](index.html). На странице GitHub выберите **Download raw file** (или откройте [raw-версию](https://raw.githubusercontent.com/lolokeksu09/WrCommunity/main/prototypes/home/v6/index.html) и сохраните файл), затем откройте сохранённый `index.html` в браузере смартфона или компьютера.

Никакие зависимости или сервер для просмотра не нужны: необходимые иллюстрации встроены в HTML.

## Что входит в прототип

- Мобильная главная: компактный визуальный блок и лента публикаций.
- Состояния гостя и участника.
- Разделы публикаций, участников и клубов.
- Демонстрационные реакции, комментарии, подписки и создание записи.
- Переключение приватности и режим «Пустая сеть».
- Макетные данные **не являются реальными аккаунтами, действиями или статистикой**.
- Без доступа к сети и без сохранения пользовательских данных на сервере.

## Известные ограничения

- Прототип не содержит действительной регистрации, защиты аккаунтов, серверной проверки приватности, API или базы данных.
- Интерактивные действия служат проверке UX и сбрасываются после перезагрузки страницы.
- Макетные данные могут имитировать функциональность, которая ещё не реализована в проекте.
- Принятые продуктовые правила хранятся в [Social Core v1](../../../docs/specs/social-core-v1.md), визуальные ориентиры — в [Design Direction v1](../../../docs/design/design-direction-v1.md).
- Пока v6 используется как опорная версия для следующего цикла дизайн-ревью; любые будущие версии не должны незаметно перезаписывать этот слепок.

## Проверка перед фиксацией

В Chromium проверены мобильные ширины **320, 360, 390, 430, 768 CSS px** (без горизонтального переполнения) и сценарии: карусель, пустая сеть, вкладки ленты, вход в деморежим участника, реакции, комментарии, создание записи, настройка приватности, поиск. Проверка относится **к автономному макету**, а не к серверному продукту.
